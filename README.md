# UOL Transport Desk

Lab Task — Implicit Intents (MAD CS02310, Section T)

A small Android app for the university Transport Office. The home screen has four buttons:
Transport Page opens uol.edu.pk in the browser, Call Transport Office opens the dialer
with the office number, Show Bus Stop opens the bus stop in Maps (all implicit intents
through one safe helper method), and Report a Problem opens a second screen with an
explicit intent carrying the student's name, where a driver's number and an email
address are validated before calling or emailing.

Built with Java in Android Studio.
